# ofor

A simple tool to open and add text to files.

## How to Install

```bash
sudo apt update
sudo apt install g++

git clone https://github.com/scurb-getCPP/ofor.git
cd ofor

g++ main.cpp ofor.cpp -o file
sudo mv fm /usr/local/bin/
```
# How to use
```bash
fm open fileName (open file)
fm add fileName (edit or create file)
if you finished, use (exit)
